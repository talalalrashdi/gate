# Portal regression — 28 October 2026

## Result and changes

The locally configured portal's catalog/read paths passed. Multiple PDFs and additional document-library tabs are supported end to end. No business schema migration or Setup.sql change was needed.

Fixed a capacity problem in document administration: large file lists were built for all editors together. Lists over50 now expand on demand, preserve their selections when closed, and show the selected count. The UI enforces the existing500-PDF limit before saving. Small lists remain open. Safety booklets still select exactly one PDF.

Updated the decision renderer test to its current dropdown, debounced search, read state and automatic refresh interface. Foundation/connection PowerShell tests now use response handling compatible with Windows PowerShell and PowerShell7 rather than assuming Invoke-WebRequest exceptions expose GetResponseStream.
