# كليريو — المشروع الكامل للتشغيل المحلي

نسخة من آخر تصميم منشور، بواجهة عربية واتجاه RTL وخط IBM Plex Sans Arabic. جميع الصور والخطوط موجودة داخل المشروع.

## التشغيل في VS Code

1. فك ضغط الملف أولًا.
2. افتح VS Code واختر File → Open Folder، ثم افتح مجلد `clerio-glass` الذي يحتوي على `package.json`.
3. ثبّت Node.js بإصدار 22.12 أو أحدث إذا لم يكن موجودًا، ثم أعد فتح VS Code.
4. افتح Terminal → New Terminal، ونفّذ:

```bash
npm ci
npm run dev
```

5. افتح `http://127.0.0.1:5173` في المتصفح. ستظهر التعديلات تلقائيًا أثناء الحفظ.
6. لإيقاف التشغيل اضغط Ctrl+C داخل الطرفية.

يحتاج `npm ci` إلى الإنترنت في المرة الأولى لتنزيل أدوات التطوير. بعد ذلك تعمل الواجهة بالصور والخطوط المحلية. ملف القفل يحافظ على إصدارات أدوات التطوير.

## فتح سريع دون تثبيت أدوات

افتح `dist/index.html` مباشرة في المتصفح. يعمل التصميم والتبويبات والبحث والتصفية والترقيم محليًا. حدّث المتصفح بعد تعديل الملفات في هذا الوضع.

## الملفات التي تعدّلها

- `dist/index.html`: هيكل الصفحة والهيدر.
- `dist/styles.css`: الألوان والمساحات والتأثير الزجاجي وتنسيقات الجوال.
- `dist/app.js`: محتويات التبويبات والرسائل والمستندات وسلوك البحث والتصفية.
- `dist/assets/glass-wheel.png`: صورة الـ Hero.
- `dist/assets/fonts/`: ملفات الخط مع رخصة OFL.
- `vite.config.js`: إعدادات التشغيل المحلي.
- `tools/layout-review.html`: شاشة مراجعة أحجام العرض، متاحة عبر `/__review` أثناء تشغيل خادم التطوير.

مجلد `dist` هنا يحتوي على الملفات المصدرية القابلة للتعديل مباشرة، ولا يتطلب المشروع خطوة بناء.

## المحتويات

خمسة تبويبات مستقلة: المشاريع والمهام، الفريق والاجتماعات، الأنظمة، التقارير والنشاط، والأرشيف والمحفوظات. يحتوي تبويب الأنظمة على الرسائل الواردة ومعدل الاستخدام ومكتبة المستندات.

الرسائل والأشخاص والمستندات بيانات تجريبية داخل `dist/app.js`. معاينة المستند تعرض نصًا تجريبيًا؛ لا تتضمن هذه النسخة ملفات PDF فعلية أو قاعدة بيانات أو تكاملًا مع أنظمة المؤسسة. البحث والتصنيف والتنقل بين الصفحات تعمل على البيانات المرفقة. إعادة تحميل الصفحة تعيد حالة الواجهة الافتراضية.

المشروع HTML وCSS وJavaScript مع Vite للتطوير، ويمكن نقله إلى أي استضافة ملفات ثابتة. الخط محلي مع رخصته، وصورة Hero مرفقة كما في النسخة المنشورة.
